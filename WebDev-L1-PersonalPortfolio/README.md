## Overview

This repository contains my personal portfolio website, created to introduce my background, highlight my technical capabilities, and showcase projects I have worked on as a Computer Science Engineering graduate.

The website features a dark visual theme, purple accents, responsive layouts, and intuitive navigation for a consistent experience across desktop and mobile devices.

## Features

- **Responsive Design** — Adapts to desktop, tablet, and mobile screens.
- **Interactive Navigation** — Includes smooth scrolling and a mobile hamburger menu.
- **About Me** — Introduces my background, interests, and career goals.
- **Education** — Presents my academic background.
- **Technical Skills** — Highlights my programming and web development skills.
- **Project Showcase** — Displays selected projects and descriptions.
- **Resume Access** — Provides access to my resume.
- **Contact Links** — Connects visitors with my professional profiles.
- **Visual Effects** — Includes hover transitions and a dark-themed interface.

## Getting Started

### Prerequisites

- A modern web browser
- Visual Studio Code (recommended)

### Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.

No additional dependencies or installation are required.

## Customization

You can personalize the portfolio by updating:

- Personal information and profile photo
- Skills and education details
- Project descriptions and repository links
- Resume file
- Contact and social profile URLs
- Colors and styles in `style.css`
