# Temperature Converter

## Project Overview
The Temperature Converter is a simple and responsive web application developed using HTML, CSS, and JavaScript. It allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

## Features
- Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- Select the input and output temperature units.
- Validate user input before conversion.
- Display the converted temperature up to two decimal places.
- Prevent temperatures below absolute zero.
- Reset the input and conversion result.
- Responsive and user-friendly interface.

## Technologies Used
- **HTML5** – Structures the web page.
- **CSS3** – Styles the interface and makes it responsive.
- **JavaScript** – Handles temperature conversion, input validation, and reset functionality.

## How to Run
1. Download or clone the project repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a temperature.
5. Select the input and output units.
6. Click **Convert** to view the result.
7. Click **Reset** to clear the input and start again.

## Temperature Conversion
The application supports the following conversions:
- Celsius to Fahrenheit and Kelvin.
- Fahrenheit to Celsius and Kelvin.
- Kelvin to Celsius and Fahrenheit.

## Validation
The application checks that the temperature input is valid and prevents values below absolute zero for the selected unit.
