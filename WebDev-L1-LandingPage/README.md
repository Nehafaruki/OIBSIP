# lumora — Creative Digital Landing Page

**OASIS INFOBYTE | Web Development and Design | Level 1 — Task 1**

Lumora is a fictional creative digital brand focused on web design, web development, and responsive digital experiences. This landing page is built using HTML5 and CSS3.
## Features
- Sticky navigation with links to Features, How it works, and Contact
- Hero section with headline, supporting text, and calls to action
- Product dashboard illustration made with HTML and CSS
- Two main content sections: Features and How it works
- Contact email and social links in the footer
- Responsive layouts for desktop, tablet, and mobile screens
- Consistent dark palette, blue accents, and readable typography
- Smooth anchor scrolling using CSS
- Reduced-motion preference support

## Files
- `index.html` — semantic page structure and content
- `style.css` — layout, theme, responsive rules, and visual styling

## Run locally
1. Download or clone this folder.
2. Open `index.html` in a browser.
3. Resize the browser window to check the desktop and mobile layouts.

No build tools or JavaScript are required.
